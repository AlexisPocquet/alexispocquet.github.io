About this site

The actual content of this site is my own, except where I needed to rephrase some wordings properly: for that, I used Claude. The style and the HTML of the site, however, come entirely from Claude, following a "nerdy, pastel and simple" theme.

How I use Claude

I use Claude (mostly Claude) for a few specific things:

  • programming, from time to time, tools that don't matter much to me and that would otherwise require me to get the hang of tools I'm fundamentally not interested in. For instance, the first version of this site, which I found ugly, or a library for writing string diagrams in Typst, which is neither usable nor stable
  • getting alternative explanations to the ones I've already been given on a topic, whether in theoretical computer science or in maths
  • easily finding recipes
  • rephrasing sentences in English and translating from French into English.

However, I don't use it to write proofs: when I tried, I never understood the lines of reasoning it produced.

Overall, I'm moderately satisfied with what I've managed to produce with Claude, this site being, in my opinion, the project whose result I like best.
